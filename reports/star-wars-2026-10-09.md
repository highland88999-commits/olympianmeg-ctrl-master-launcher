## What was built

A full saga playthrough, Episodes I–IX in movie order. Galaxy map → travel to planets →
walkable 3D zones (or fly zones) → complete each world's chapter beat → unlock the
next episode. Progress persists per user in `localStorage` (`olympus:starwars:progress`).

**19 worlds, 9 chapters:**

| Ep | Chapter | Worlds |
|----|---------|--------|
| I | The Phantom Menace | Tatooine (podrace circuit), Naboo (Theed) |
| II | Attack of the Clones | Coruscant (Jedi Temple), Kamino (Tipoca City), Geonosis (arena) |
| III | Revenge of the Sith | Mustafar (fortress) |
| IV | A New Hope | Yavin 4, Alderaan (fly: memorial debris field), Death Star (fly: trench run) |
| V | The Empire Strikes Back | Hoth (Echo Base), Dagobah (swamp hut), Bespin (Cloud City) |
| VI | Return of the Jedi | Endor (speeder-bike forest run) |
| VII | The Force Awakens | Jakku (Niima Outpost), Takodana (Maz's castle), Starkiller Base (cannon) |
| VIII | The Last Jedi | Ahch-To (Jedi village), Crait (salt flats) |
| IX | The Rise of Skywalker | Exegol (Sith citadel) |

Chapter intro crawls are original summaries (not the films' opening crawls).
Alderaan is film-accurate: a destroyed-world memorial you fly, not walk.

## Files (all new, published)

- `app/star-wars/page.jsx` — shell: menu → chapter crawl → galaxy map → zone.
  Walk mode reuses the shared standard (`lib/world/walk-controls`,
  `lib/world/walk-input`, `components/world/WalkJoystick`). Fly mode: drag-steer,
  auto-forward, checkpoint rings. HUD with objective banner + checkpoint pips,

  canvas textures; zero external network requests at runtime.
- `app/star-wars/data.js` — chapters, planets, pure progression helpers.
- `app/star-wars/tests/data.test.mjs` (12 tests), `tests/builders.test.mjs` (67 tests).

## Quality bar

- Zero external requests: all textures procedural canvas, no CDNs/fonts/hotlinks.
- Solid geometry: circle colliders push out (slide/deflect); fly debris deflects;
  only star-map transitions pass through.
- Lighting: emissive is small localized accents only (lava, windows, beacons,
  checkpoint rings); all meshes flat-shaded, no shadow maps (mobile perf).
- Mobile-first: touch joystick + drag-look, clean minimal HUD, safe-area constants
  mirrored from the Hawkins shell.
